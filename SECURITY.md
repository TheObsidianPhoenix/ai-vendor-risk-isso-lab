# Security Policy

This is a cybersecurity portfolio and learning project. It uses only
fictional, synthetic data. No real vendor, customer, or personal
information is stored in this repository or the deployed application.

## Reporting a vulnerability

Please use GitHub's "Report a vulnerability" button on the Security
tab of this repository. Do not open a public issue for security problems.

## Secrets

No credentials, API keys, or AWS access keys are stored in this
repository. Secret scanning and push protection are enabled.
