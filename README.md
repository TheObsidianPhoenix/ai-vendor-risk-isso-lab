# AI Vendor Risk & ISSO Security Lab

An AI-powered third-party risk management (TPRM) application, built and
governed the way an Information Systems Security Officer (ISSO) would
secure a real AI system.

> **Core governance rule:** AI recommendations are advisory. Final vendor
> risk acceptance and approval authority remains with an authorized human
> reviewer. This is enforced in code and IAM, not just in the AI prompt.
