# sample-data/

Fictional vendor security documents used for testing. Created in Phase 3.

**Rules**

- Synthetic data only. No real company, vendor, person or document is copied or referenced.
- Every vendor name is invented, and every document says it is fictional.
- Some documents contain deliberate problems (hidden instructions, missing evidence, conflicting answers) so the security tests have something to catch. Each problem is listed below so nobody mistakes it for an accident.

| Vendor (planned) | Documents | Deliberate problem |
|---|---|---|
| Nimbus Notes AI | Questionnaire, security policy packet | Hidden prompt injection; conflicting breach-notice timelines |
| Copperline Backup | Questionnaire | Encryption claimed with no evidence |
| Kestrel Payroll Cloud | Questionnaire, SOC 2 summary | None (the clean control case) |
