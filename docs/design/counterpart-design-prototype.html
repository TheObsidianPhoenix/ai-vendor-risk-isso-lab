What happens next

Your browser uploads directly to an encrypted quarantine bucket through a short-lived, single-file link. The app server never handles the file bytes, and nothing is processed until it passes every check.

  • File type is verified from its contents, not its name.
  • Macros, embedded files, and oversize files are rejected.
  • Hidden text (white text, tiny fonts, metadata) is flagged as possible prompt injection.
  • Only extracted plain text, never the file itself, is sent to the model, and only for this one vendor.

Scoring rules

The rules engine is deterministic: the same evidence states always produce the same score. The AI only proposes an evidence state for each control, with a citation.

Rule set v1.0 · changes require an approved pull request

Evidence states

Points per control
StatePointsMeaning
Verified0Control described and backed by independent evidence (e.g., audit report).
Unverified+6Vendor claims the control; no supporting evidence supplied.
Conflict+8Two vendor sources disagree. Always surfaced to the reviewer.
Absent+12No mention, or questions left blank.
Critical gap+25A critical control is absent or contradicted.

Classification bands

0–24 Low25–49 Moderate50–74 High75+ Critical

Score is the sum of points, capped at 100.

Floor rules

Any critical gap sets the classification to at least High.

Two or more critical gaps set it to Critical.

A prompt-injection flag adds no points but always requires human review and logs a security event.

If the AI's evidence state lacks a citation, it's treated as Absent, never Verified.

EU AI Act classification

Proposed

Proposed category: not high-risk. The system assesses businesses (vendors), not natural persons, and doesn't appear to fall under the Annex III use cases, which center on decisions about people such as employment and creditworthiness.

Obligations still considered: AI literacy for staff using the system (Article 4). Human-oversight and record-keeping practices modeled on the high-risk requirements are adopted voluntarily.

To verify in Phase 10: final Annex III text and the current application timeline, which has been subject to amendment proposals.
